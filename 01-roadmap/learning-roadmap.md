# My Data Analytics Learning Roadmap

## My Starting Point

- **Level:** Complete beginner
- **Tools available:** Microsoft Excel and Google Sheets
- **Goal:** Develop practical data analytics skills and prepare for entry-level data analyst opportunities.

---

## Phase 1: Excel and Google Sheets

**Goal:** Learn to organize, clean, analyze, and summarize data using spreadsheets.

Topics:
- Spreadsheet basics, rows, columns, and cell references
- Data types and formatting
- Sorting and filtering
- Basic formulas: SUM, AVERAGE, MIN, MAX, COUNT
- Logical functions: IF, AND, OR
- Conditional formatting
- Data cleaning and removing duplicates
- Lookup functions: XLOOKUP and VLOOKUP
- SUMIF, SUMIFS, COUNTIF, and COUNTIFS
- Pivot tables and charts
- Basic dashboard creation

**Milestone:** Complete a spreadsheet-based sales analysis project.

## Phase 2: Statistics Fundamentals

**Goal:** Understand the statistical concepts used in data analysis.

Topics:
- Mean, median, and mode
- Range, variance, and standard deviation
- Percentages and ratios
- Probability basics
- Distributions and outliers
- Correlation versus causation
- Sampling and bias
- Introduction to hypothesis testing

**Milestone:** Analyze a dataset and explain its key statistical findings.

## Phase 3: Python Fundamentals

**Goal:** Learn to write basic Python programs.

Topics:
- Variables and data types
- Strings and numbers
- Lists, tuples, dictionaries, and sets
- Conditional statements
- Loops
- Functions
- Working with files
- Error handling
- Basic problem-solving exercises

**Milestone:** Write small Python programs independently.

## Phase 4: Python for Data Analytics

**Goal:** Use Python to work with real datasets.

Topics:
- Jupyter Notebook
- NumPy fundamentals
- pandas Series and DataFrames
- Reading CSV and Excel files
- Filtering and sorting data
- Handling missing values and duplicates
- Grouping and aggregating data
- Merging datasets
- Basic statistical analysis

**Milestone:** Clean and analyze a real-world dataset using pandas.

## Phase 5: SQL

**Goal:** Retrieve and analyze data stored in relational databases.

Topics:
- Tables, rows, columns, and data types
- SELECT, FROM, and WHERE
- ORDER BY and LIMIT
- DISTINCT
- Aggregate functions
- GROUP BY and HAVING
- JOIN operations
- CASE statements
- Subqueries
- Common table expressions
- Window functions

**Milestone:** Complete a set of SQL analysis exercises using a sample database.

## Phase 6: Data Visualization

**Goal:** Present data clearly and communicate insights effectively.

Topics:
- Choosing appropriate chart types
- Bar charts, line charts, and scatter plots
- Histograms and box plots
- Matplotlib and Seaborn
- Introduction to Power BI or Tableau
- Dashboard design
- Data storytelling

**Milestone:** Create a dashboard that communicates meaningful insights.

## Phase 7: Exploratory Data Analysis (EDA)

**Goal:** Investigate datasets, identify patterns, and generate useful questions.

Topics:
- Understanding dataset structure
- Data quality checks
- Missing-value analysis
- Outlier detection
- Univariate analysis
- Bivariate analysis
- Correlation analysis
- Visualization and interpretation
- Communicating findings

**Milestone:** Complete an end-to-end exploratory data analysis project.

## Phase 8: Portfolio Projects

**Goal:** Demonstrate practical analytical skills.

Planned projects:
1. Sales performance analysis using Excel
2. Customer or business data analysis using SQL
3. Exploratory data analysis using Python
4. Interactive dashboard using a visualization tool
5. End-to-end data analytics project

**Milestone:** Publish well-documented projects in GitHub repositories.

## Phase 9: Interview Preparation

**Goal:** Prepare to apply for entry-level data analyst roles.

Topics:
- Excel interview questions
- Statistics interview questions
- Python interview questions
- SQL interview questions
- Data visualization questions
- Business case studies
- Project explanations
- Resume preparation
- Practice interviews
