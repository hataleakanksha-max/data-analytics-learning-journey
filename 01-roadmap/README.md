# Data Analytics Learning Roadmap

Welcome to my Data Analytics Learning Journey!

This folder contains my learning plan, milestones, and progress as I build practical data analytics skills from the ground up.

## Learning Path

1. Microsoft Excel and Google Sheets
2. Statistics Fundamentals
3. Python Fundamentals
4. Python for Data Analytics
5. SQL
6. Data Visualization
7. Exploratory Data Analysis (EDA)
8. Portfolio Projects
9. Interview Preparation

## Learning Approach

- Learn concepts step by step.
- Practice with hands-on exercises.
- Document notes and key takeaways.
- Build small projects to apply what I learn.
- Track progress consistently.

## Goal

Build the practical skills and portfolio needed to pursue entry-level data analytics opportunities.
