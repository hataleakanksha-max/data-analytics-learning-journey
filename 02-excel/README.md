# Excel and Google Sheets — Learning Module

## Overview

This module is the starting point of my Data Analytics Learning Journey. I will learn Microsoft Excel and Google Sheets from the basics and gradually move toward practical data analysis.

The goal is to understand how to organize, clean, analyze, summarize, and visualize data using spreadsheets.

## Learning Objectives

By the end of this module, I aim to be able to:

- Navigate spreadsheets confidently.
- Organize and format datasets.
- Sort and filter data.
- Use formulas and functions to perform calculations.
- Clean datasets and handle common data-quality issues.
- Summarize data using PivotTables.
- Create charts and basic dashboards.
- Communicate useful insights from data.

## Learning Roadmap

### 1. Spreadsheet Fundamentals
- Workbooks, worksheets, rows, columns, and cells
- Cell references: relative, absolute, and mixed
- Data types and number formatting
- Basic spreadsheet navigation

### 2. Basic Formulas and Functions
- SUM
- AVERAGE
- MIN and MAX
- COUNT, COUNTA, and COUNTBLANK
- Basic arithmetic operations

### 3. Logical Functions
- IF
- AND and OR
- Nested IF statements
- IFERROR

### 4. Data Cleaning
- Identify and remove duplicates
- Find and handle missing values
- Remove unnecessary spaces
- Standardize text and date formats
- Split data into columns
