# Lesson 7: Sorting and Filtering Data

## Overview

This lesson covers sorting and filtering data in Microsoft Excel and Google Sheets.

Sorting arranges records in a specific order, while filtering displays only the records that meet selected conditions. These techniques help analysts organize datasets, identify important information, and answer business questions efficiently.

## Learning Objectives

By completing this lesson, I practised how to:

- Sort numerical data from largest to smallest and smallest to largest.
- Sort text alphabetically.
- Filter records by category.
- Filter numerical data using greater-than and less-than conditions.
- Combine filters across multiple columns.
- Understand the difference between AND and OR conditions.
- Keep complete records together while sorting.
- Clear filters and restore the full dataset.

## Topics Covered

1. Sorting data
2. Filtering data
3. Filtering text categories
4. Filtering numerical values
5. Combining multiple conditions
6. Understanding AND and OR
7. Safe spreadsheet practices

## Tools Used

- Microsoft Excel
- Google Sheets

## Practical Application

I practised analyzing a fictional stationery-store dataset containing products, categories, quantities sold, prices, and total sales.

The exercises included identifying the highest-selling product, filtering Accessories and Electronics products, and combining numerical and category conditions.

## Key Takeaways

- Sorting changes the order of records.
- Filtering displays records that meet selected conditions.
- AND requires all specified conditions to be true.
- OR requires at least one specified condition to be true.
- Sorting the complete table helps preserve relationships between columns.
- Clearing filters makes the complete dataset visible again.
