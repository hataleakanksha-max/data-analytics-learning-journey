
# Lesson 8: Important Excel Functions

## Overview

This lesson introduces important Excel and Google Sheets functions used for business data analysis and reporting.

## Functions Covered

- `IF()` — Returns a result based on a condition.
- `COUNTIF()` — Counts cells matching one condition.
- `SUMIF()` — Adds values matching one condition.
- `COUNTIFS()` — Counts cells or records matching multiple conditions.
- `SUMIFS()` — Adds values matching multiple conditions.

## Learning Objectives

By completing this lesson, I learned how to:

1. Classify data automatically using logical conditions.
2. Count records based on text and numeric criteria.
3. Calculate totals for specific categories.
4. Apply multiple conditions to business data.
5. Interpret comparison operators such as `>`, `<`, `>=`, and `<=`.

## Practical Applications

These functions can be used for:

- Sales target tracking
- Department-wise employee counts
- Category-wise revenue calculations
- Identifying high-value orders
- Business performance reporting
