# Lesson 6: Basic Data Cleaning

## Overview

This lesson introduces basic data-cleaning techniques using Microsoft Excel and Google Sheets.

Data cleaning helps identify and correct data-quality problems before analysis. It improves consistency and helps prevent misleading business conclusions.

## Learning Objectives

By completing this lesson, I practised how to:

- Identify duplicate records.
- Remove confirmed duplicates safely.
- Recognize inconsistent text and extra spaces.
- Use `TRIM()` to remove unnecessary spaces.
- Use `PROPER()` to standardize capitalization.
- Identify missing values.
- Understand why missing values should not automatically be replaced with zero.
- Preserve original data while cleaning.

## Topics Covered

1. Duplicate records
2. Inconsistent text values
3. Extra spaces in text
4. The `TRIM()` function
5. The `PROPER()` function
6. Missing values and data quality
7. Safe data-cleaning practices

## Tools Used

- Microsoft Excel
- Google Sheets

## Practical Application

I practised cleaning a fictional stationery-store sales dataset containing duplicate records, inconsistent capitalization, extra spaces, and missing quantities.

## Key Takeaways

- Duplicate records can inflate sales totals and affect analysis.
- `TRIM()` removes unnecessary spaces.
- `PROPER()` capitalizes the first letter of each word.
- Missing values should be investigated rather than replaced with assumptions.
- Keeping original data makes cleaning easier to verify and reverse.
