## Exercise 2: Electronics Sales Dataset

### Objective

Practice entering, editing, and organizing data.

### Dataset

| Product | Category | Quantity Sold | Price per Unit | Sale Date |
|---|---|---:|---:|---|
| Laptop | Electronics | 2 | 45000 | 2026-10-01 |
| Mouse | Accessories | 10 | 500 | 2026-10-02 |
| Keyboard | Accessories | 5 | 1200 | 2026-10-03 |
| Monitor | Electronics | 3 | 12000 | 2026-10-04 |
| Headphones | Accessories | 8 | 2000 | 2026-10-05 |

These are fictional practice records.

### Tasks

- [x] Enter the dataset in Microsoft Excel.
- [x] Enter the dataset in Google Sheets.
- [x] Select the range `A1:E6`.
- [x] Explain the meaning of the selected range.
- [x] Identify text, numeric, and date values.
- [x] Explain why consistent data types matter.
- [x] Correct an incorrectly entered value.
- [x] Compare basic spreadsheet behavior in Excel and Google Sheets.

### Understanding Check

**1. What does `A1:E6` include?**

Five columns and six rows, for a total of thirty cells.

**2. What does each row represent?**

One product record containing its associated information.

**3. What does each column represent?**

One field or variable, such as Product, Category, or Quantity Sold.

**4. Why use one header row?**

A single header row makes column meanings clear and helps analytical tools interpret the dataset.

**5. What is the problem with `Ten` in a numeric quantity column?**

It introduces an inconsistent data type and may interfere with calculations. If the intended quantity is confirmed to be ten, it should be corrected to the numeric value `10`.
