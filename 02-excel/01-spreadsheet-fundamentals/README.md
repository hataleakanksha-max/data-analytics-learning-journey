# Spreadsheet Fundamentals

## Overview

This module introduces the basic concepts needed to work confidently with spreadsheets in Microsoft Excel and Google Sheets.

## Topics

- Understanding workbooks and worksheets
- Understanding rows, columns, and cells
- Entering and editing data
- Organizing simple datasets
- Navigating a spreadsheet
- Saving and naming spreadsheet files
- Comparing basic Excel and Google Sheets workflows

## Practical Exercise

**Exercise:** Create a small sales dataset.

The exercise will introduce structured data entry and help me understand how information is organized in a spreadsheet.
