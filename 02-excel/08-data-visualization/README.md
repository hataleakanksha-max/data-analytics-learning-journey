# Lesson 9: Data Visualization in Excel and Google Sheets

## Overview

This lesson covers data visualization fundamentals, chart selection, chart interpretation, and the creation of a basic sales dashboard.

## Topics Covered

- Introduction to data visualization
- Column and bar charts
- Line charts
- Pie charts and percentage distribution
- Scatter plots
- Choosing the right chart for a business question
- Interpreting charts and communicating insights
- Creating a basic sales dashboard

## Learning Objectives

By completing this lesson, I learned how to:

1. Select charts based on the business question.
2. Compare sales values across products.
3. Identify trends and changes over time.
4. Calculate percentage contributions to total sales.
5. Interpret business metrics accurately.
6. Build a basic dashboard using formulas and charts.

## Tools Used

- Microsoft Excel or Google Sheets

## Practical Project

**Project:** Sales Performance Dashboard

The dashboard uses a sample dataset of six products and includes:

- Total sales
- Number of products listed
- Category-wise sales
- Sales by product chart
- Sales distribution by category chart
- Business insights based on the results

## Key Finding

The sample dataset contains total sales of ₹76,000. Electronics contributes ₹70,000, or approximately 92.1% of total sales. Laptop generates the highest sales value, while Notebook has the highest quantity sold.
