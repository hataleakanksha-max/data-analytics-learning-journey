# Lesson 5: Cell References

## Overview

This lesson introduces relative, absolute, and mixed cell references in Microsoft Excel and Google Sheets.

Cell references allow formulas to use values stored in other cells. Understanding how references behave when formulas are copied is essential for building accurate, efficient, and reusable spreadsheets.

## Learning Objectives

By completing this lesson, I learned how to:

- Understand relative cell references.
- Use absolute cell references to lock a row and column.
- Understand mixed cell references.
- Identify how cell references change when formulas are copied.
- Apply cell references to calculate discounts.
- Use formulas in both Microsoft Excel and Google Sheets.

## Topics Covered

1. Relative references
2. Absolute references
3. Mixed references
4. Copying formulas across rows and columns
5. Calculating discounts using cell references

## Tools Used

- Microsoft Excel
- Google Sheets

## Practical Application

I practised calculating product discounts using original prices and discount rates.

I also explored how absolute references can keep a standard discount rate fixed while formulas are copied to multiple rows.

## Key Takeaway

Relative references adjust when formulas are copied. Absolute references keep both the row and column fixed, while mixed references lock either the row or the column.
