# Basic Formulas and Cell References

## Overview

This module introduces basic spreadsheet formulas and cell references using Microsoft Excel and Google Sheets.

Formulas help automate calculations, reduce manual effort, and update results when the underlying data changes.

## Learning Objectives

By completing this lesson, I learned how to:

- Understand what spreadsheet formulas are.
- Write formulas using cell references.
- Perform addition, subtraction, multiplication, and division.
- Calculate sales using quantity and price.
- Copy formulas down a column.
- Understand relative cell references.
- Explain how formulas recalculate when input values change.

## Topics Covered

1. Introduction to formulas
2. Basic arithmetic operators
3. Using cell references in formulas
4. Copying formulas using the fill handle
5. Introduction to relative cell references
6. Automatic recalculation of formula results

## Tools Used

- Microsoft Excel
- Google Sheets

## Practice

I practiced calculating product sales using the formula:

`=Quantity*Price`

I also copied formulas to other rows and observed how the cell references adjusted automatically.

## Key Takeaway

Formulas allow spreadsheets to perform calculations automatically. Using cell references makes calculations easier to maintain because the results update when the referenced values change.
