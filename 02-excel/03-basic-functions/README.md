# Basic Functions in Excel and Google Sheets

## Overview

This module introduces four essential spreadsheet functions used to summarize and analyze numerical data.

The lesson was practiced in Microsoft Excel and Google Sheets using a fictional stationery store sales dataset.

## Learning Objectives

- Understand the difference between formulas and functions.
- Use `SUM()` to calculate totals.
- Use `AVERAGE()` to calculate averages.
- Use `MIN()` to find the smallest value.
- Use `MAX()` to find the largest value.
- Understand cell ranges and the colon (`:`) operator.
- Apply spreadsheet functions to a business problem.

## Functions Covered

| Function | Purpose |
|---|---|
| `SUM()` | Calculates the sum of numerical values |
| `AVERAGE()` | Calculates the arithmetic mean |
| `MIN()` | Finds the smallest numerical value |
| `MAX()` | Finds the largest numerical value |

## Tools Used

- Microsoft Excel
- Google Sheets

## Practical Project

Analyzed sales for five stationery products by calculating individual sales, total revenue, average sales, lowest sales, and highest sales.

## Results

| Metric | Result |
|---|---:|
| Total Revenue | ₹8,500 |
| Average Sales per Product | ₹1,700 |
| Lowest Sales | ₹500 |
| Highest Sales | ₹4,000 |

## Key Takeaway

Spreadsheet functions make calculations faster and easier to maintain. They help analysts summarize datasets and identify useful business information.
